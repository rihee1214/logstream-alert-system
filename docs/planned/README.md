# Planned Overview

> 이 디렉토리는 현재 **MVP 진행 과정에서 우선순위가 낮거나**,  
> **구현 복잡도 또는 고려 사항이 많아 후속 작업으로 미룬 정책/기능/설계 항목**들을 정리하는 공간입니다.  
> 추후 프로젝트가 안정화되거나 필요성이 명확해질 경우, 이 문서들을 기반으로 다시 구현하거나 정책화를 진행합니다.

---

## 목적

- **시간상 여유가 없어 미루게 된 작업 항목들**을 정리합니다.
- **기술적 철학, 정책적 결정**에 시간이 많이 걸릴 경우, 임시로 계획만 수립하고 문서화합니다.
- 추후 **설계 변경 또는 기능 확장 시 참고**할 수 있는 기반 문서로 활용합니다.

---

## 예시 항목

- 복잡한 로깅 정책 철학 (예: `Resilient Tracing Policy`)
- 컨텍스트 전파 전략 고도화 (MDC, WebClient 등)
- 추적 ID 관련 복원 전략 및 UI 연동 정책
- 운영 도구 또는 시각화 도구 도입 검토 사항

---

## 구성 방식

- 각 문서는 **하나의 계획(Planned Item)** 단위로 관리되며, 필요 시 하위 항목으로 분리될 수 있습니다.
- 문서 제목과 내용은 **나중에 다시 돌아왔을 때 이해하기 쉬운 수준으로 작성**되어야 합니다.
- 문서 내부에는 다음 항목이 포함되는 것을 권장합니다:
	- 계획 배경
	- 미룬 이유
	- 고려 사항 또는 결정되지 않은 요소
	- 추후 작업을 위한 힌트 또는 선행 작업

---

## 참고

- 이 디렉토리는 실제 동작하는 코드나 설정을 담지 않으며, **계획서 수준의 문서만 포함**합니다.
- 구현 완료 시 체크박스에 체크하고, 관련 문서를 `docs/`, `architecture/`, `decision/` 등 적절한 위치로 이동합니다.
- 각 문서는 **실제로 구현되지 못한 기능/서비스 단위**를 나타내며, 해당 문서가 구현되면 실 서비스 영역으로 이전하는 것을 권장합니다.
