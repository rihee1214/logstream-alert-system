# 02. operational_docs Overview

> 이 디렉토리는 운영 및 관리에 중요한 요소들을 넣어두었음
 
---

## 디렉토리 구조

```
operational_docs/  
├── contracts/ # 시스템 간 연동을 위한 명세 및 데이터 계약 정의서
│   ├─ .....   # 예: 로그 포맷 정의서, API 명세, 데이터 스키마 등
│   └─ .....
└── guide/     # 운영·배포·설정에 필요한 실무 가이드 문서
	├─ .....   # 예: 환경 변수 설명, 배포 순서, 트러블슈팅 매뉴얼 등
	└─ .....
```

---
## 설명

### contracts/

- **주요 내용**: 시스템 간 연동을 위한 데이터 구조 정의, 외부 시스템과의 통신 규약, 로그 포맷, API 명세 등
- **작성 대상**: 서비스 개발자, 통합 API 소비자, 플랫폼 엔지니어
- **예시 항목**:
  - `/logging/logstructure-contract.md` – 로그 구조 및 필드 설명
  - `/observability/HTTP-Call-Metadata.md` – HTTP Api call 시 헤더에 들어가야 하는 메타 데이터

### guide/

- **목적**: 시스템 운영 및 개발을 위한 실무 가이드 제공
- **작성 대상**: 운영 담당자, 신규 개발자, 유지보수 인력
- **서브 디렉토리 구성**:
	- `/config/`
		- 시스템 설정 관련 문서  
		- *예: application.properties, 환경 변수, JVM 옵션 등 설정 항목 정리*
	- `/development/` 
		- 개발 시 참고해야 할 문서  
		- *예: 기능 개발 전 고려사항, 설계 가이드라인 등*
	- `/usage/` 
		- 운영자의 시스템 기동 및 운영 관련 매뉴얼  
		- *예: 서비스 시작/종료 방법, 운영 시 주의사항, 명령어 모음 등*
