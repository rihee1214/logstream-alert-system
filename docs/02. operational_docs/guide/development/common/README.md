# Common 모듈 안내

이 모듈은 **모듈 간 공통으로 사용하는 정책·규칙의 계약(Enum)**을 관리하는 프로젝트입니다.  
다른 업무 팀과의 연동 시, 표준화된 계약을 기반으로 안정적인 통신과 데이터 처리를 보장하기 위해 존재합니다.

## 포함 내용
- 로그의 모든 **기본 필드 이름**
- 통신 헤더 키 값
- 그 외 모듈 간 공유해야 하는 **관심사에 대한 계약 요소**

## 사용 지침
- **로직(비즈니스 코드)을 포함하지 않습니다.**
- 계약 요소는 **추가만 가능**하며,  
  **수정 시 다른 팀 및 서비스에 광범위한 영향**을 미칠 수 있으니 반드시 사전 협의 후 진행해야 합니다.
- 추후 변경·삭제 가능성이 있는 요소는 이 모듈에 포함하지 마십시오.

## 변경 시 유의사항
- 본 모듈은 여러 서비스에서 직접 참조하므로,  
  **코드 변경이 배포 연쇄**를 유발할 수 있습니다.
- 변경 사항은 반드시 **관련 팀과의 합의**를 거친 후 적용하십시오.

## 예시 (포함되는 계약 요소 유형)
- **`common.constant.annotation`**  
  → 로그 필드 중 **필수 값**에 대한 규격을 나타내는 어노테이션.  
	  이 어노테이션은 모든 로그 생산 서비스와 소비 서비스가 **공통으로 인식해야 하는 계약**이며,  
	  필수 필드 검증 및 표준 준수 여부를 보장하는 데 사용됩니다.  
	  변경 시 전 서비스에 영향을 줄 수 있으므로 **신중하게 추가·수정**해야 합니다.
- **`common.constant.message`**  
  → 로그 데이터에 포함되는 필드 정보(메시지 규격)
- **`common.constant.storage`**  
  → Logging Service에서 DB Insert 시 사용하는 스키마 Enum
- 그 외, 서비스 간 계약 필드, 표준화된 식별자, 공통 에러 코드 등

> 위와 같이, 서비스 경계를 넘나드는 **정책·규칙·데이터 구조의 계약 요소**들을 정의합니다.
