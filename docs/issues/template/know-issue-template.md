## 🚨업그레이드 주의사항 (Upgrade Cautions)
(업그레이드 시 신경 써야 할 대상과 고려해야 할 문제들을 정리한다)

- **업그레이드시 신경써야하는 대상**
  - 어떤 라이브러리(Spring Boot, Gradle, JDK 등)의 버전 업그레이드에 의해 영향을 받을 수 있는지 명시한다.
  - 현재 설정, 의존성, 구조가 새 버전과 충돌하거나 동작 방식이 바뀔 가능성이 있는 대상을 식별한다.
- **업그레이드시 발생 가능한 문제**
  - 특정 기능이 deprecated되거나, 제거될 가능성.
  - 이전까지 동작하던 코드, 설정, 빌드 스크립트 등이 정상적으로 동작하지 않을 가능성.
  - 기존에 의존하던 경고 무시 방식(-XX:+옵션 등)이 통하지 않는 상황.
- **업그레이드시 신경 써야 하는 부분**
  - 새로운 버전에 맞춰 수정하거나 대응해야 할 사항(예: 추가 설정 필요, 대체 API 적용 등).
  - 변경된 사양에 따라 추가 테스트나 검증이 필요한 영역(예: 로깅 포맷 변화, 테스트 환경 변화).
  - 사전 점검할 항목(예: jvmArgs 정상 적용 여부, logging event 구조 변화 확인 등).
