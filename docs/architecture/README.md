# Architecture Overview

>이 디렉토리는 전체 시스템의 아키텍처 설계 및 관련 문서를 정리하는 공간입니다.  
>전반적인 구조부터 각 구성 요소의 세부 설계, 아키텍처 결정 사항까지 포함합니다.

---
## 구조
```
architecture/
├─ MsaLogHandleProjects.drawio.png          # 전체 아키텍처 PNG 이미지
├─ MsaLogHandleProjects.drawio                 # 아키텍처 설계 원본 (Draw.io)
├─ architecture.md                                        # 전체 아키텍처 설명 문서
├─ notes/                                                       # 아키텍처 결정 사항 문서들
│   └─ 아키텍처 결정 문서들
└─ details/                                                     # 세부 아키텍처 흐름 및 컴포넌트별 구조 문서
   └─ 세부 아키텍처 구성에 대한 문서들
```
---
## 설명
- **`architecture.md`**  
    → 상위 디렉토리(`architecture/`)에 대한 대표 설명 문서로 사용합니다.  
    아키텍처 개요, Drawio 이미지 요약, notes/details 폴더 목적 등을 포함하면 좋습니다.
- **`notes/`**  
    → 아키텍처 결정 사항, 예: "로그 전파 정책", "추적 ID 설계 철학" 등, 정책성과 철학 중심의 기록 저장소입니다.
- **`details/`**  
    → 실제 서비스 흐름(예: mockup 요청 흐름, 계층 간 역할 분리 등)과 컴포넌트 내부 설계 관련 문서를 보관합니다. 시스템 구조를 _코드 수준보다 약간 상위_에서 설명합니다.

---
## 참고
- 문서들은 변경될 수 있는 정책적 요소와 기술적 판단을 반영하므로, 관련 결정 문서(`notes/`)를 참고하시는 것을 권장합니다.
